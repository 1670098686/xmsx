文献阅读整理Agent

项目简介

文献阅读整理Agent是一款面向各大专业在读大学生的轻量化、本地化桌面端文献智能整理工具，旨在解决大学生学术科研、论文写作过程中，文献整理效率低、文献资源管理混乱、核心信息提炼不准、学习笔记零散难复用等核心痛点。
当前大学生开展课程论文、毕业论文撰写及科研调研工作时，需查阅海量中外文献，传统人工摘抄、分类、总结、批注的方式耗时费力，且极易出现信息遗漏、文献丢失、笔记与原文脱节等问题，极大拉高了科研入门门槛，降低学术创作效率。
本项目基于Python开发，依托成熟的文本解析与本地存储技术，实现文献智能解析、系统化分类管理、联动式笔记批注、批量导出备份等一站式功能。软件全程本地离线运行，无需联网、无需付费，轻量化适配主流Windows电脑，零基础学生可快速上手，能够大幅降低文献整理的时间成本，规范个人学术资源管理，精准提炼文献核心内容，全方位助力大学生学术学习与科研创作。

技术栈

- 编程语言：Python
- GUI界面：PyQt5
- PDF解析：PyPDF2、pdfplumber
- 文本处理：jieba
- 本地数据存储：SQLite
- 文件读写：os、pathlib
  
核心功能

1. 智能文献解析
支持PDF、TXT、Word等主流学术文献格式导入，自动拆分文献结构，精准提炼研究背景、核心观点、实验方法、创新点、研究结论等关键信息，生成标准化结构化解读报告。
2. 系统化文献管理
搭建本地专属文献资源库，支持自定义分类文件夹、标签归档，可通过标题、作者、关键词、时间等多维度检索文献，实现文献资源统一收纳、快速查找与规范管理。
3. 在线笔记批注
提供在线笔记编辑、原文高亮、段落批注功能，支持学习心得与对应文献段落绑定，可随时修改补充，解决传统笔记零散、无法联动原文、复用率低的问题。
4. 导出备份与系统配置
支持解读报告、个人笔记、文献目录批量导出，提供本地数据一键备份恢复功能；同时支持解析规则、存储路径、界面样式自定义，适配全学科用户使用习惯。

项目优势

- 离线免费：全程本地离线运行，无联网上传，保护学术隐私，无任何付费订阅成本
- 轻量化易用：软件体积小、启动快，适配低配电脑，界面简洁，零基础快速上手
- 精准高效：智能解析替代人工重复工作，可降低80%以上文献整理耗时
- 场景适配：针对大学生学习、科研场景定制，适配文、理、工多学科文献整理需求

## 快速开始

### 环境依赖

- 操作系统：Windows 10/11（全程本地化，无任何网络请求）
- Python：3.11（推荐，3.9+ 亦可）
- 依赖库版本见 `literature_agent/requirements.txt`：
  PyQt5 5.15.11、pdfplumber 0.11.10、PyPDF2 3.0.1、python-docx 1.2.0、
  jieba 0.42.1、reportlab 4.2.2、cryptography 50.0.1、pytest 9.1.1

### 安装步骤

```powershell
# 1. 进入源码目录
cd literature_agent

# 2.（建议）创建并激活虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. 安装固定版本依赖
python -m pip install -r requirements.txt
```

### 启动方式

```powershell
# 在 literature_agent 目录下执行
python main.py
```

首次启动自动在用户目录 `~/.literature_agent/` 下创建 SQLite 数据库（9 张表 +
种子解析规则/标签/默认配置）与日志，文献与备份的默认存储路径可在
「管理中心 → 存储路径配置」中自定义并一键迁移。

## 目录结构

```
literature_agent/
├── main.py                 # 程序入口：DB 初始化 → 配置 → 主题 → 主窗口
├── config/                 # 全局常量、主题配色、系统设置读写
├── ui/                     # 界面展示层：主窗口、通用组件、各功能页面
│   ├── widgets/            # 按钮、弹窗、Toast、Loading、折叠块、QThread Worker
│   └── pages/              # 导入/解析/检索/笔记/管理中心子页面
├── business/               # 业务逻辑层：统一返回 (code, data, msg)
├── tool_layer/             # 工具层：PDF/TXT/DOCX 提取、jieba 分词、导出、文件工具
├── data_layer/             # 数据持久层：SQLite 单例连接 + 各表 DAO（全参数化）
├── utils/                  # 自定义异常、日志、通用工具
├── resources/              # 图标、QSS 主题、默认模板
├── output/                 # 运行输出（备份缓存，已 gitignore）
└── tests/                  # pytest 单元/集成/E2E/边界测试
```

分层强制约束：UI 层只调用 business 层；business 调 tool/data 层；
tool 层不碰数据库；data 层只做 CRUD，禁止逆向调用与跨层访问。

## 快捷键

| 快捷键 | 作用页面 | 功能 |
|---|---|---|
| Ctrl+S | 笔记批注 | 立即保存（落库防抖中的笔记） |
| Ctrl+E | 文献解析 | 按系统默认格式导出当前解析报告 |

关闭程序时自动记住当前页面、管理中心子模块与检索条件，下次启动自动恢复。
