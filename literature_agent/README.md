# 文献管理系统

## 项目简介

本系统是一个基于 Python 的文献管理系统，支持文献的导入、分类、检索和阅读功能。系统采用模块化设计，各功能模块独立开发，通过统一的接口进行交互。

## 快速开始

1. 克隆仓库到本地
2. 安装依赖：`pip install -r requirements.txt`
3. 运行主程序 `python main.py`

## 功能模块

- **文献导入**：支持多种文件格式（PDF、DOCX、TXT等）
- **文献管理**：提供文献的增删改查功能
- **文献阅读**：支持批注、笔记、书签等功能
- **AI 辅助**：AI 可以帮助用户快速找到相关文献
- **标签管理**：支持自定义标签分类
- **系统设置**：可配置系统参数

## 系统架构

系统采用四层架构：
1. **数据层**：使用 SQLite 数据库存储文献元数据和全文索引
2. **业务层**：处理文献的业务逻辑，包括 CRUD 操作
3. **接口层**：提供 RESTful API 接口
4. **UI 层**：提供用户界面

## 使用说明

1. 启动系统后，进入主界面
2. 点击"导入文献"按钮，选择本地文献文件
3. 系统将自动解析文献并展示文献的基本信息
4. 支持批量操作和标签管理

## 开发环境

- Python 3.10+
- 依赖管理：pip
- 数据库：SQLite
- 日志记录：使用 Python 标准日志模块

## 注意事项

- 系统仅支持本地文献管理，不提供云端同步功能
- 请勿修改数据库文件，以免影响系统稳定性
