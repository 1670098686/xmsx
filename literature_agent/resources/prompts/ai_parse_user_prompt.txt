【开场白】
【精度要求】
请先通读再归纳：原件请逐页阅读 PDF/文档全文，全文文本请从头到尾通读，覆盖摘要、关键词、引言、方法、实验、讨论、结论、参考文献以及表格、图注、页眉页脚中的有效信息，不得跳读或只依据首尾内容作答。
一、语句要求：除参考文献与 "keywords" 外，每个维度字段都必须写成一段或多段意思完整的陈述句（主谓宾完整、句末使用句号），严禁用短语、词组罗列或编号要点清单代替完整句子。
二、归纳要求：即使原件没有对应的章节标题，也必须依据通读所得自行归纳作答，不得留空、不得返回“未识别/无”；仅当通读全文后确无线索时，才用一句完整句子说明“原文未明确涉及该方面内容”。
三、忠实要求：所有结论必须来自原件；数据、年份、方法名称、结论程度等关键信息须与原件一致，未在原件中出现的信息不要编造。
请严格按下列字段输出 JSON：
- "research_background": 研究背景：用完整语句陈述选题背景、现实问题与研究动因，150-300字
- "core_view": 核心观点：用完整语句陈述作者的主要论点、论据与核心主张，150-300字
- "research_method": 研究方法：用完整语句说明研究设计、数据来源、分析方法与实施过程，100-200字
- "innovation_point": 创新点：用完整语句陈述相较已有研究的新颖之处与贡献，100-200字
- "research_conclusion": 研究结论：用完整语句总结最终结论、适用边界与建议，150-300字
- "reference_list": 参考文献：严格按原件文末著录原样逐条列出，每条单独一行，不增删、不改写、不合并；确无参考文献时填空字符串 ""
- "keywords": 附加信息，从原件中提炼 5-15 个规范、专业的关键词，组成字符串数组；该字段独立存在，不得用它替代上面任何维度的语句段落
输出格式：只输出一个 JSON 对象，不要输出任何解释或 Markdown 围栏，示例：{"research_background":"...","core_view":"...","research_method":"...","innovation_point":"...","research_conclusion":"...","reference_list":"...","keywords":["..."]}
