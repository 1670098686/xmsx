严格遵循项目规则中的四层分包，**禁止跨层逆向调用**。

```

│  UI 展示层 (ui/)                                                │
│  - 仅渲染界面、捕获事件                                          │
│  - 调用 business 接口，接收 (code, data, msg) 三元组            │
│  - 耗时操作必须走 QThread                                        │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│  Business 业务层 (business/)                                    │

│  - 调用 tool_layer 和 data_layer                                │

                │                           │
                ▼                           ▼
┌─────────────────────────────┐   ┌─────────────────────────────────┐

│  - 文件路径操作               │   │  - 不包含任何业务判断逻辑          │
│  - 导出文件生成               │   │                                 │
│  ⚠️ 禁止访问数据库            │   │                                 │
└─────────────────────────────┘   └─────────────────────────────────┘
```

## 三、数据库设计（SQLite 8 张表 + 关联表改进）

### 3.1 设计改进说明（相对于概要设计原文）

| # | 原设计问题 | 改进方案 |
|---|-----------|---------|
| 1 | `literature_info.tag_id` 使用逗号分隔字符串存储多标签 | 拆分为独立的 **`literature_tag`** 多对多关联表，建立 proper junction |
| 2 | 无外键约束和索引 | 为所有关联字段增加 `FOREIGN KEY` 和 `INDEX`，提升检索性能 |
| 3 | 缺少备份记录追踪 | 新增 **`backup_record`** 表，记录每次备份时间、大小、内容范围 |
| 4 | `parse_rule` 表 `parse_dimension` 用 varchar 存"全维度提取"描述 | 改用 **JSON 字段**存储维度开关、权重配置，灵活可扩展 |
| 5 | `literature_info` 缺少文件大小和唯一标识 | 新增 `file_size`、`file_hash` 字段，用于去重校验 |
| 6 | 所有表无创建时间索引 | 为常用排序/检索字段建立索引 |
| 7 | `literature_info.file_path` 存绝对路径，切换存储配置后失效 | **改存相对路径**（相对于 `system_config` 中的 `literature_path` 基准），运行时通过 `file_helper.resolve_path()` 拼接还原绝对路径 |
| 8 | `literature_info.category_id` 与 `literature_tag` 关联表看似冗余 | **保留 `category_id` 作为反规范化快速字段**：分类是一对一归属场景（一篇文献通常只归一个分类），标签是多对多场景；查询分类归属直接走 `category_id` O(1)，标签走关联表，两者职责互补 |

> **路径解析约定**：`literature_info.file_path` 存储形如 `2024/xxx.pdf` 的相对路径，运行时 `file_helper.resolve_path(rel_path, "literature")` 从 `system_config` 读取基准路径拼接。`system_config` 切换存储路径时，只需迁移物理文件 + 更新基准路径，数据库相对路径无需改动。

### 3.2 完整 DDL（db_init.py 使用的建表脚本）

```sql
PRAGMA foreign_keys = ON;

-- ============================================================
-- 1. 文献信息表（literature_info）
--    存储用户导入的所有学术文献基础信息
-- ============================================================
CREATE TABLE IF NOT EXISTS literature_info (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    literature_title    VARCHAR(255)  NOT NULL DEFAULT '',
    literature_author   VARCHAR(100)  NOT NULL DEFAULT '',
    publish_time        VARCHAR(20)   NOT NULL DEFAULT '',
    journal_source      VARCHAR(255)  NOT NULL DEFAULT '',
    literature_type     VARCHAR(20)   NOT NULL DEFAULT '',     -- PDF / TXT / DOCX
    file_path           VARCHAR(500)  NOT NULL,                 -- 相对路径（相对于 system_config.literature_path 基准，运行时拼接还原绝对路径）
    file_size           INTEGER       NOT NULL DEFAULT 0,       -- 文件字节数
    file_hash           VARCHAR(64)   NOT NULL DEFAULT '',       -- SHA256 用于去重
    category_id         INTEGER       NOT NULL DEFAULT 0,       -- 所属分类ID，0=未分类
    is_parsed           TINYINT       NOT NULL DEFAULT 0,       -- 0未解析 1已解析 2解析中 3解析失败
    create_time         DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time         DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_lit_title       ON literature_info(literature_title);
CREATE INDEX IF NOT EXISTS idx_lit_author      ON literature_info(literature_author);
CREATE INDEX IF NOT EXISTS idx_lit_category    ON literature_info(category_id);
CREATE INDEX IF NOT EXISTS idx_lit_type        ON literature_info(literature_type);
CREATE INDEX IF NOT EXISTS idx_lit_parsed      ON literature_info(is_parsed);
CREATE INDEX IF NOT EXISTS idx_lit_create      ON literature_info(create_time);
CREATE INDEX IF NOT EXISTS idx_lit_hash        ON literature_info(file_hash);

-- ============================================================
-- 2. 文献-标签关联表（literature_tag）【新增：替代原 tag_id 逗号分隔】
--    多对多关联，一篇文献可对应多个标签/分类
-- ============================================================
CREATE TABLE IF NOT EXISTS literature_tag (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    literature_id    INTEGER       NOT NULL,
    tag_id          INTEGER       NOT NULL,
    bind_time       DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (literature_id) REFERENCES literature_info(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id)        REFERENCES category_tag(id)    ON DELETE CASCADE,
    UNIQUE(literature_id, tag_id)
);
CREATE INDEX IF NOT EXISTS idx_lt_lit    ON literature_tag(literature_id);
CREATE INDEX IF NOT EXISTS idx_lt_tag    ON literature_tag(tag_id);

-- ============================================================
-- 3. 文献解析报告表（literature_report）
--    存储智能解析生成的结构化报告
-- ============================================================
CREATE TABLE IF NOT EXISTS literature_report (
    id                      INTEGER PRIMARY KEY AUTOINCREMENT,
    literature_id            INTEGER       NOT NULL,
    research_background      TEXT          NOT NULL DEFAULT '',
    core_view                TEXT          NOT NULL DEFAULT '',
    research_method          TEXT          NOT NULL DEFAULT '',
    innovation_point         TEXT          NOT NULL DEFAULT '',
    research_conclusion      TEXT          NOT NULL DEFAULT '',
    reference_list           TEXT          NOT NULL DEFAULT '',
    parse_time               DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    rule_id                  INTEGER       DEFAULT 1,               -- 可为空：外键 ON DELETE SET NULL 要求列允许 NULL
    FOREIGN KEY (literature_id) REFERENCES literature_info(id) ON DELETE CASCADE,
    FOREIGN KEY (rule_id)       REFERENCES parse_rule(id)      ON DELETE SET NULL
);
CREATE INDEX IF NOT EXISTS idx_report_lit ON literature_report(literature_id);

-- ============================================================
-- 4. 笔记批注表（literature_note）
--    存储笔记、批注、高亮，精准绑定原文段落
-- ============================================================
CREATE TABLE IF NOT EXISTS literature_note (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    literature_id    INTEGER       NOT NULL,
    paragraph_pos    VARCHAR(50)   NOT NULL DEFAULT '',          -- 原文段落位置标识
    note_content     TEXT          NOT NULL DEFAULT '',
    note_type        VARCHAR(20)   NOT NULL DEFAULT 'paragraph', -- paragraph=段落批注 global=全局笔记
    highlight_style  VARCHAR(30)   NOT NULL DEFAULT '',          -- 高亮样式/颜色
    create_time      DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time      DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (literature_id) REFERENCES literature_info(id) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_note_lit ON literature_note(literature_id);

-- ============================================================
-- 5. 分类标签表（category_tag）
--    统一存储分类目录和标签（tag_type 区分）
-- ============================================================
CREATE TABLE IF NOT EXISTS category_tag (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    tag_type        TINYINT       NOT NULL DEFAULT 2,            -- 1=分类目录 2=标签
    tag_name        VARCHAR(50)   NOT NULL,
    tag_color       VARCHAR(20)   NOT NULL DEFAULT '#000000',
    parent_id       INTEGER       NOT NULL DEFAULT 0,            -- 父级分类ID，顶级为0
    sort_order      INTEGER       NOT NULL DEFAULT 0,            -- 同级别排序
    create_time     DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_tag_type    ON category_tag(tag_type);
CREATE INDEX IF NOT EXISTS idx_tag_parent  ON category_tag(parent_id);
CREATE UNIQUE INDEX IF NOT EXISTS idx_tag_name_unique 
    ON category_tag(tag_type, tag_name, parent_id);

-- ============================================================
-- 6. 解析规则配置表（parse_rule）
--    存储默认与自定义解析规则，rule_detail 为 JSON 灵活配置
-- ============================================================
CREATE TABLE IF NOT EXISTS parse_rule (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    rule_name       VARCHAR(50)   NOT NULL,
    subject_type    VARCHAR(20)   NOT NULL DEFAULT '通用',      -- 文/理/工/医/通用
    rule_detail     TEXT          NOT NULL DEFAULT '{}',        -- JSON: 维度开关/权重/精度
    precision_level TINYINT       NOT NULL DEFAULT 3,           -- 1-5级
    is_default      TINYINT       NOT NULL DEFAULT 0,
    create_time     DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP
);
-- rule_detail JSON 结构示例:
-- {
--   "dimensions": {
--     "research_background": true,
--     "core_view": true,
--     "research_method": true,
--     "innovation_point": true,
--     "research_conclusion": true,
--     "reference_list": true
--   },
--   "weights": {
--     "research_background": 1.0,
--     "innovation_point": 1.5,
--     "research_conclusion": 1.5
--   },
--   "keyword_top_n": 20
-- }

-- ============================================================
-- 7. 系统配置表（system_config）
--    存储全局系统参数（配置化键值对形式，灵活扩展）
-- ============================================================
CREATE TABLE IF NOT EXISTS system_config (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    config_key      VARCHAR(100)  NOT NULL UNIQUE,
    config_value    TEXT          NOT NULL DEFAULT '',
    config_desc     VARCHAR(255)  NOT NULL DEFAULT '',
    update_time     DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP
);
-- 预置配置键:
--   literature_path     文献存储路径
--   report_path         解析报告存储路径
--   note_path           笔记存储路径
--   backup_path         备份文件存储路径
--   auto_save_time      自动保存频率（秒）    默认 30
--   backup_cycle        自动备份周期（天）    默认 7
--   export_default_type 默认导出格式          默认 PDF
--   ui_style            界面样式（light/dark）默认 light
--   parse_default_rule  默认解析规则ID        默认 1
--   precision_default   默认解析精度          默认 3
--   auto_save_debounce  自动保存防抖（秒）    默认 1

-- ============================================================
-- 8. 备份记录表（backup_record）【新增】
--    追踪每次备份的元信息，支持恢复和清理
-- ============================================================
CREATE TABLE IF NOT EXISTS backup_record (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    backup_name     VARCHAR(100)  NOT NULL,
    backup_path     VARCHAR(500)  NOT NULL,
    backup_size     INTEGER       NOT NULL DEFAULT 0,           -- 字节数
    backup_type     VARCHAR(20)   NOT NULL DEFAULT 'full',      -- full=全量 incremental=增量
    content_scope   VARCHAR(100)  NOT NULL DEFAULT 'all',       -- all/literature/note/config
    backup_time     DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    backup_status   TINYINT       NOT NULL DEFAULT 1            -- 1=成功 0=失败
);
CREATE INDEX IF NOT EXISTS idx_backup_time ON backup_record(backup_time);

-- ============================================================
-- 9. 操作日志表（operation_log）
--    记录关键业务操作，支撑个人资源中心和问题追溯
-- ============================================================
CREATE TABLE IF NOT EXISTS operation_log (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    operate_type    VARCHAR(30)   NOT NULL,                      -- 导入/解析/导出/删除/配置修改等
    operate_content VARCHAR(500)  NOT NULL DEFAULT '',
    literature_id    INTEGER       NOT NULL DEFAULT 0,           -- 关联文献ID，0表示无关联
    operate_time    DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    operate_status  TINYINT       NOT NULL DEFAULT 1            -- 1=成功 0=失败
);
CREATE INDEX IF NOT EXISTS idx_log_time   ON operation_log(operate_time);
CREATE INDEX IF NOT EXISTS idx_log_type   ON operation_log(operate_type);
CREATE INDEX IF NOT EXISTS idx_log_lit    ON operation_log(literature_id);
```

### 7.1 单例数据库连接（data_layer/db_connect.py）

```python
import sqlite3
import threading

class DatabaseManager:
    _instance = None
    _lock = threading.Lock()

    def __new__(cls, db_path: str = None):
        with cls._lock:
            if cls._instance is None:
                cls._instance = super().__new__(cls)
                cls._instance._init(db_path)
            return cls._instance

    def _init(self, db_path: str):
        self.db_path = db_path or os.path.join(
            os.path.expanduser("~"), ".literature_agent", "literature_agent.db"
        )
        os.makedirs(os.path.dirname(self.db_path), exist_ok=True)
        self.conn = sqlite3.connect(self.db_path, check_same_thread=False)
        self.conn.row_factory = sqlite3.Row
        self.conn.execute("PRAGMA foreign_keys = ON")

    def get_conn(self) -> sqlite3.Connection:
        return self.conn

    def execute(self, sql: str, params: tuple = ()) -> sqlite3.Cursor:
        cur = self.conn.cursor()
        cur.execute(sql, params)
        self.conn.commit()
        return cur

    def close(self):
        if self.conn:
            self.conn.close()
```

### 7.2 耗时任务 QThread 封装（ui/widgets/worker.py）

```python
from PyQt5.QtCore import QThread, pyqtSignal

class TaskWorker(QThread):
    """通用耗时任务线程"""
    progress = pyqtSignal(int, str)    # 进度百分比 + 描述
    finished_ok = pyqtSignal(object)  # 成功返回
    finished_err = pyqtSignal(str)    # 失败错误信息

    def __init__(self, task_func, *args, **kwargs):
        super().__init__()
        self.task_func = task_func
        self.args = args
        self.kwargs = kwargs

    def run(self):
        try:
            result = self.task_func(*self.args, **self.kwargs, 
                                     progress_callback=self.progress.emit)
            self.finished_ok.emit(result)
        except Exception as e:
            self.finished_err.emit(str(e))
```

### 7.4 路径安全校验（tool_layer/file_helper.py）

```python
def sanitize_path(path: str, base_dir: str = None) -> str:
    """防止路径穿越攻击"""
    resolved = os.path.realpath(os.path.abspath(path))
    if base_dir:
        base_resolved = os.path.realpath(os.path.abspath(base_dir))
        if not resolved.startswith(base_resolved):
            raise PermissionError(f"路径越权: {path}")
    return resolved
```

## 附录 A：数据库版本迁移预留

在 `db_init.py` 中实现简单版本迁移：
```python
SCHEMA_VERSION = 1

def migrate_if_needed(conn: sqlite3.Connection):
    # 读取 user_version
    cur = conn.execute("PRAGMA user_version")
    current_version = cur.fetchone()[0]
    if current_version < SCHEMA_VERSION:
        # 执行增量迁移脚本
        _migrate_v1_to_v2(conn)
        conn.execute(f"PRAGMA user_version = {SCHEMA_VERSION}")
```
